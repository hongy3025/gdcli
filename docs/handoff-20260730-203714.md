### Key design decisions

- **Single editor contract**: One `--editor` process per pytest session, enforced by PID counting.
- **gdcli embeds GDScript at compile time**: `include_dir!` in `cli/src/embedded_addon.rs` — GDScript changes need `touch` + `cargo build`.
- **GDAPI_HANDLER_TIMEOUT_MS=180000**: Raised from 5s default to 180s to fix export/run timeouts.
- **FileTransport is primary runtime transport**: `EngineDebugger` path is effectively dead due to channel check mismatch (`_on_runtime_capture` checks `channel == "protocol"` but is registered for `"gdapi"`).
- **M6 audit tests fail in full suite**: M3's `reset_shared_state` clears audit log. M6's own tests record entries but they're lost. These tests pass when M6 is run alone (44/44).
