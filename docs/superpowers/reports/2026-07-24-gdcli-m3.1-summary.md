## 实施期间的发现

1. **`runtime/status` 在 headless 下真实可达 `connected`，`transport: "file"`** — M3 closure report 列出的 Godot 4.7 headless 限制被 file transport 完全绕开。

2. **M3 阶段遗留：35 个数据面 route 仍跑在 editor 进程** — M3.1 plan § Global Constraints 第 19 行明确"35 个 runtime 路由全部一行不动"，所以这是有意保留的设计。在 headless 下，game 进程的 `RuntimeMain` SceneTree 在 editor 的 SubViewport 容器里，但 `_resolve` 起始固定为 `SceneTree.root = Window`，找不到 game node。M3.1 不修这个；失败分析 + 独立 plan 候选在 `2026-07-24-m3.1-failures.md`。

3. **24 个 M3 route 缺 `ok: true` envelope** — 之前 route handler 直接 `res.json(result.get("result", {}))`，导致测试 `payload.get("ok") is True` 失败。Task 6 顺手补上 envelope。

4. **`runtime_node_ops.tree` visited 数组 bug** — 原代码 `_serialize_node(root, 0, max_depth, [root])` 首节点就被识别为 cycle。改为传 `[]` 后正常递归。
